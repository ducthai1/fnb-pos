# Chỗ tài liệu cũ nói khác code

Ghi lại khi viết sổ tay: tài liệu (decision-log, logic-catalog, feature-map, chữ trên màn) nói một đằng, code làm một nẻo. Sổ tay viết theo **code**; ở đây chỉ ghi lại để người phụ trách quyết định sửa tài liệu hay sửa code. Không mục nào ở đây đã được sửa.
